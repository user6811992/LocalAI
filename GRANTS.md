# Grant Application Guide

Open-source grants that fit LocalAI's "no telemetry + local AI + privacy" mission.

## 1. NLnet (nlnet.nl) — Recommended

**Amount:** €5k–€50k
**Focus:** Privacy, decentralization, open-source infrastructure
**Timeline:** Rolling applications, ~3 month review
**Website:** https://nlnet.nl/propose/

### Eligibility
- Open-source project (MIT license ✓)
- Privacy-focused or decentralized
**Why LocalAI fits:**
- No telemetry, no cloud dependencies
- Local AI with Ollama backend
- Privacy-first reverse engineering tools
- Open-source, community-driven

### Application template

**Project name:** LocalAI
**One-line description:** A local AI web UI with Ollama backend, reverse-engineering tools, and zero telemetry.

**What problem does it solve?**
Cloud AI services require sending sensitive data (code, binaries, personal info) to third parties. LocalAI runs entirely on the user's machine — no cloud, no telemetry, no tracking. It's especially valuable for reverse engineers and developers who handle proprietary or sensitive code.

**What will the grant fund?**
- Cross-platform installer improvements (Linux/macOS/Docker) ✓ (already done)
- Model routing by task type (code vs. reasoning)
- RE workspace enhancements (binary upload, session management)
- Documentation and onboarding for non-technical users
- Accessibility improvements

**Deliverables:**
- Working cross-platform installers
- Model routing system
- RE workspace UI
- User documentation
- Test suite

## Tips for applying

1. **Be specific about deliverables** — "Add model routing" not "improve AI"
2. **Show traction** — GitHub stars, commits, releases, user count
3. **Emphasize privacy** — this is your strongest differentiator
4. **Budget realistically** — don't over-ask; €10k–20k is a good range for a solo dev
5. **Include a timeline** — 3–6 months for deliverables
6. **Link to the repo** — make sure README is polished (screenshots, clear setup)
