# Tool, Plugin, Skill & MCP Configuration Guide

Comprehensive configuration reference for everything installed for AegisAI / OpenCode.

## 1. OpenCode Configuration Files

### Global: `~/.config/opencode/opencode.jsonc`
Applies to every project. Contains the working plugin set and global MCP servers.

```jsonc
{
  "$schema": "https://opencode.ai/config.json",
  "plugins": [
    "opencode-mem",
    "opencode-usage-monitor",
    "envsitter-guard",
    "opencode-gemini-auth",
    "opencode-antigravity-auth",
    "oh-my-opencode",
    "opencode-swarm",
    "opencode-dcp",
    "@cortexkit/opencode-magic-context",
    "@honcho-ai/opencode-honcho",
    "cc-safety-net",
    "@heretek-ai/opencode-rea",
    "opencode-llm-proxy",
    "opencode-synced",
    "basemind-opencode",
    "opencode-rag-plugin",
    "opencode-telemetry"
  ],
  "mcp": {
    "rea": { "command": "rea", "args": ["--mcp"] },
    "netvein": { "command": "netvein", "args": ["serve", "--mcp"] },
    "lemma": { "command": "npx", "args": ["-y", "lemma"] }
  }
}
```

### Project: `.opencode/opencode.jsonc` (AegisAI repo)
Same shape, scoped to this repo. OpenCode merges project config over global.

### Project: `mcp-config.json` (AegisAI repo)
Legacy/parallel MCP config used by the web UI's RE tooling:
```json
{
  "mcpServers": {
    "rea": { "command": "rea", "args": ["--mcp"], "env": { "PATH": "%PATH%" } },
    "netvein": { "command": "netvein", "args": ["serve", "--mcp"] },
    "lemma": { "command": "npx", "args": ["-y", "lemma"] }
  }
}
```

### Plugin options
Some plugins accept an object form instead of a string:
```jsonc
{ "package": "opencode-ntfy.sh", "options": { "topic": "your-ntfy-topic" } }
```
Use this for `opencode-ntfy.sh` (requires a topic) or any plugin needing config.

## 3. MCP Servers

### REA (Ghidra-backed)
Requires env vars:
```bash
GHIDRA_INSTALL_DIR=C:\Ghidra\ghidra_12.1.4_PUBLIC
JAVA_HOME=C:\Program Files\Eclipse Adoptium\jdk-21.0.13.9-hotspot
REA_JADX_MCP_JAR=C:\Tools\jadx-mcp\jadx-headless-mcp-0.7.1-all.jar
```
Command: `rea --mcp`

### netvein (web RE)
Auto-boots Chrome on port 9222 on first tool call. Optional env:
```bash
CDP_HOST=127.0.0.1
CDP_PORT=9222
```
Command: `netvein serve --mcp`

### lemma (local memory)
No config needed. Runs via npx. Command: `npx -y lemma`

## 4. CLI Tools

### argus
```sh
argus detect <file|dir>     # magic bytes + build markers -> kind
argus plan <file|dir>       # ordered commands for that kind
argus recon <file>          # bounded tier-1 inventory
argus doctor               # host tool availability + fallbacks
argus ref <topic> [query]  # progressive-disclosure references
argus install --agent opencode  # install skill
```
Installed at: `C:\Users\Poonjab\AppData\Roaming\npm\argus.cmd`

### netvein
```sh
netvein serve --mcp        # run as MCP server
netvein init [path]        # init .netvein workspace
netvein install            # auto-wire into agents
netvein status [path]      # inspect workspace
```

## 5. OpenCodeRAG (semantic code search)

Config: `.opencode/opencode-rag.json`
```json
{
  "indexing": {
    "includeExtensions": [".ts", ".js", ".py", ".md", ...],
    "excludePatterns": ["node_modules", ".git", "dist"]
  },
  "embeddings": { "provider": "ollama", "model": "nomic-embed-text" }
}
```
CLI: `opencode-rag index`, `opencode-rag query <q>`, `opencode-rag status`, `opencode-rag clear`

## 6. Environment Variables (AegisAI)

| Var | Purpose |
|---|---|
| `AEGISAI_TOOL_BUDGET` | Max tools per agent request (default 64) |
| `GHIDRA_INSTALL_DIR` | Ghidra install path |
| `JAVA_HOME` | Java home for REA |
| `REA_JADX_MCP_JAR` | jadx-mcp jar path |
| `GITHUB_TOKEN` | Higher GitHub API rate limits (RE project search) |
| `CDP_HOST` / `CDP_PORT` | netvein Chrome debugging endpoint |

## 7. Verification

- `argus doctor` — check host RE tools
- `opencode-rag status` — index status
- OpenCode: `/reload` after config changes
- Logs: `~/.local/share/opencode/log/opencode.log`
